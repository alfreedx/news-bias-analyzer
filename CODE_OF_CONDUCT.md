# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## En resumen

- Trata a todas las personas con respeto, sea cual sea su ideología. Este es un proyecto sobre
  pluralismo informativo: el desacuerdo político es bienvenido; los ataques personales, no.
- Argumenta con fuentes, no con descalificaciones de medios, periodistas o lectores.
- No se toleran acoso, insultos, lenguaje discriminatorio ni la publicación de datos personales ajenos.

## Aplicación

Las personas que mantienen el proyecto pueden editar o eliminar comentarios, incidencias y
contribuciones que incumplan este código, y bloquear temporal o permanentemente a quien lo haga.

Para informar de un incumplimiento, usa el aviso privado de GitHub
(pestaña *Security* → *Report a vulnerability*) indicando que se trata de una cuestión de conducta.
Todas las denuncias se revisarán con confidencialidad.
